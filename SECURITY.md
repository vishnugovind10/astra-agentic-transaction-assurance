# Security Policy

Astra is currently a documentation-only pre-build specification. It is not a deployed payment system and has not undergone a security audit.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise, contact the repository owner through a private channel listed on their GitHub profile. Include affected document or component, impact, and reproduction details where safe.

Do not include private keys, seed phrases, live credentials, or sensitive transaction data in a report.
