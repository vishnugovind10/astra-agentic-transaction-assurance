# Contributing

This repository is in a documentation-only pre-build phase for the QDay Aevum Builder Challenge. Until the official build window opens on 16 November 2026 at 06:00 UTC, contributions must remain non-executable documentation and research. Do not submit application code, smart contracts, scripts, build configuration, or executable tests before that time.

Please open an issue or pull request for documentation corrections. Keep claims traceable to sources, mark assumptions, and do not include confidential data, credentials, or private keys.
